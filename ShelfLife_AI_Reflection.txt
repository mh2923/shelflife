# ShelfLife - AI Use Reflection & Prompt Log

## 1. AI Tools Used

Our group used ChatGPT throughout different phases of the ShelfLife project for development guidance, debugging, and code improvements. AI was used as a support tool, while the team reviewed suggestions, tested the application, and made decisions about the final implementation.

## 2. Representative Prompt Log

| Prompt | AI Suggestion | Decision |
|---|---|---|
| **1. API Integration:** "How can we integrate the Open Library API into ShelfLife to search for books and display their details?" | Use React state and effects to fetch book data, process API responses, and handle loading and error states. | **Accepted and tested.** |

## 3. Example of an AI Error and Correction

During final testing, we discovered that Open Library returned an HTTP 422 error for search queries shorter than three characters.

ChatGPT initially suggested adding a minimum-length validation check using the existing error state. Although this displayed a validation message, it also showed the API's "Try Again" button. Clicking that button repeated the previous search instead of resolving the invalid input.

After identifying this issue through testing, we revised the implementation by introducing a separate `validationError` state. This allowed input validation messages to appear below the search bar while keeping the Try Again button exclusively for API failures.

This demonstrated that an AI-generated solution can appear correct initially but still introduce unexpected behavior.

## 4. Rejected AI Suggestion

During search validation improvements, ChatGPT initially suggested using the existing API error state to display messages for searches shorter than three characters. We rejected this approach after testing because it incorrectly displayed the "Try Again" button for invalid user input. Instead, we used a separate validationError state to handle input validation independently from API errors.

## 5. Reflection

ChatGPT helped our group in parts of our ShelfLife's development, particularly with integrating external API data, managing shared application state, debugging errors, and improving code organization.

However, we learned that AI suggestions should not be accepted without testing. Some solutions required adjustments to match our project requirements or to fix problems discovered during implementation.

Overall, AI helped support the development process, while practical testing, debugging, and reviewing the code remained important responsibilities for our team.
